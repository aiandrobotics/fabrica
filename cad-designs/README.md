# CAD Designs & 3D Printed Models

This folder contains the CAD source files, 3D printing assets (STL/STEP/3MF), parameter definitions, and assembly models for the **Fabrica Cloth Folding Robot**.

## Directory Structure

- `parts/` - Individual 3D printable part models (Motorized Module, Follower Module, Base Module, Interface Module)
- `assemblies/` - Full 3D grid assembly models (e.g., standard 4×3 configuration)
- `exports/` - STL and STEP export files ready for slicing and printing
